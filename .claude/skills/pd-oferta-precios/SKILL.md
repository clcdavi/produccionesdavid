# Oferta y precios

## Reglas fijas
- Voseo rioplatense. Moneda y números **solo los que David confirme**: nunca inventes precios, costos ni horas. Si faltan, pedilos o dejá `$___` marcado.
- No prometas resultados fuera del control de la agencia (ventas, seguidores). Prometé lo que se entrega: piezas, tiempos, revisiones. "Entrega en 48 a 72 horas" es promesa oficial.
- Todo precio nuevo requiere aprobación de David antes de comunicarse.

## Modos
| Modo | Qué hace |
|---|---|
| `oferta` | convierte la descripción básica del servicio en una oferta concreta y fácil de entender |
| `promesa` | una frase centrada en el resultado para el cliente |
| `paquetes` / `tresprecios` | estructura Básico, Recomendado, Premium; cada uno con un rol (entrada, objetivo, ancla) |
| `anclaje` | ordena precios para que el paquete objetivo se perciba como la mejor decisión |
| `valor` / `premium` | sube el valor percibido sin sumar horas (proceso, entregables, velocidad, acompañamiento) |
| `garantia` | garantías posibles y honestas (revisiones, reposición de toma, plazo) |
| `bonus` | complementos baratos de dar y valiosos de recibir |
| `nombre` / `metodo` | nombre memorable y pasos propios del proceso de trabajo |
| `objecionprecio` | respuestas a "es caro" / "lo pienso" (se complementa con `pd-dm-ventas`) |
| `rentabilidad` | con horas, costos y capacidad mensual que dé David, detecta si el paquete conviene |

## Salida
- Tabla comparativa de paquetes: qué incluye, para quién, tiempo de entrega, precio (de David).
- Cómo presentarlo: orden de los paquetes, texto de cada uno, frase de cierre.
- Una versión para Instagram (sin sonar a aviso) y otra para WhatsApp.
- Supuestos usados y datos que faltan.

## Criterios
- Cada paquete tiene una razón de existir; evitá diferencias confusas.
- Presentá el valor y el resultado antes del precio.
- Pensá en el rubro: un restaurante, una peluquería y una inmobiliaria no compran igual.
